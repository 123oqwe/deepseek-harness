# First-100 Recovery Implementation Wave Map

> **For agentic workers:** REQUIRED SUB-SKILL: use `subagent-driven-development` or `executing-plans` to execute this map task by task. Track each micro-PR independently; no red test, generated evidence, or unverified status file is merged as a false PASS.

**Goal:** recover all 100 First-100 epics as one dependency-safe, canonical, composed, fault-qualified DSH system, starting with a corrected and re-signed manifest.

**Architecture:** every epic is an aggregation key, not a PR. Its implementation is split into `C` (contract/schema plus a red-to-green contract test), `P` (replaceable provider or an explicit N/A), `U` (consumer plus shipping composition), and `F` (fault/security/real-task qualification). Cross-epic dependencies target the predecessor's accepted `F` boundary; within an epic the order is `C → P → U → F`, skipping only an explicitly justified N/A.

**Tech stack:** TypeScript/Node/pnpm/Cordis, Vitest and repository E2E configurations, JSON/YAML schemas, SQLite or declared durable providers, OS/container/remote execution providers, TypeScript/Python SDKs, and Q1/Q2/Q3 qualification profiles.

## 3. Micro-PR and merge protocol

### 3.1 Stage semantics

- `C(n)` freezes the service/schema/state machine/error taxonomy and adds a focused contract test that is first observed RED on the parent SHA, then made GREEN inside the same PR. No failing test is merged to protected master. `n` is the exact number of touched files and must be 1–5.
- `P(n)` adds one reference/fake/durable/real provider behind the contract. It cannot change the public contract. Provider-less architecture, qualification, or pure-consumer epics say `P=N/A` with a reason.
- `U(n)` wires real consumers through public services and boots a keyless shipping/example profile. Direct construction of a provider, private deep imports, or a test-only composition is a merge blocker.
- `F(n)` adds denial, unload, fault, crash, race, security, or real-task coverage. Raw observations are CI artifacts, not committed source. Q3 absence is `NOT_RUN`, never PASS.
- Brace notation expands to exact repository-relative paths: `a/{b,c}` means files `a/b` and `a/c`. A path can be revisited by a later micro-PR; the count applies per PR, not per epic.

### 3.2 Universal merge gates

1. **M:** v1.1 signed bundle verifies; selected base/path migration map is current; every listed predecessor has an `ACCEPTED` signed `F` verdict on the merge-queue SHA.
2. **C:** pre-change RED observation exists; schema/codec/unknown-version and backward/forward migration behavior are explicit; contract tests are green; no duplicate truth is introduced.
3. **P:** provider conformance, tenant scope, lifecycle disposal, crash/corruption behavior, and unsupported-platform semantics pass. Security uncertainty fails closed.
4. **U:** consumer resolves only the public service; keyless Q1 and installed-tarball Q2 compositions boot and expose the capability; `off|shadow|enforce` provenance is visible.
5. **F:** item acceptance, required scenario(s), hard invariant, cleanup, and 13-entry evidence package pass an independent verifier for the exact merge-queue SHA. A live provider claim additionally needs Q3.
6. Shared files/packages are serialized by owner lease. A merge invalidates descendants' evidence; descendants rebase, rerun, and re-sign. A wave closes only when every row's F gate is accepted.

### 3.3 Rollback codes

| Code | Boundary |
|---|---|
| A | Additive contract: before consumers, revert it; after adoption, retain decoder/schema and disable the provider/consumer through the gate until a versioned migration removes it. |
| K | Kernel/security: rollback may switch only to the previous independently verified fail-closed implementation; never restore an insecure bypass or lower a deny floor. |
| D | Durable state: stop writers, fence owners, restore the pre-wave checkpoint, run backward migration, then reopen; schema files remain readable until retention expires. |
| X | External effect: stop dispatch, preserve ledger/receipts, reconcile ambiguous effects, then disable composition; never “rollback” by replaying an irreversible action. |
| R | Wire/protocol: keep old decoder and negotiated version, disable new commands/resources, and dual-read until all persisted cursors/events migrate. |
| Q | Qualification-only: revert the test/gate/runner; it has no product state and cannot make a previously failed product claim pass. |
| UI | Surface: disable the UI module and retain server enforcement/read models; clients never own canonical state. |
