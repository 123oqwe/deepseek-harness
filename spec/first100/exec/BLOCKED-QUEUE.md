- **Resolution, effective immediately:**
  1. No Writer/Reviewer subagent may run `git checkout`/`switch`/`reset --hard`/other branch-or-tree-state-mutating commands in the shared worktree. Branch/tree state belongs solely to the Supervisor, changed only between subagent dispatches.
  2. A Writer that needs to commit on an attempt branch must either (a) be dispatched with `isolation:"worktree"` (an isolated git worktree; auto-cleaned if unchanged), or (b) have the Supervisor check out the target branch first, then dispatch a Writer that never touches git branch commands itself.
  3. New invariant: record `git branch --show-current` + HEAD immediately before every non-isolated dispatch; verify both are unchanged immediately after the subagent returns. If either changed, the subagent's entire output is discarded (no partial salvage) — restore the intended branch/tree state and redo the dispatch (isolated this time, if the task needs to touch git).
