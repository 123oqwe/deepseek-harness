# Agent Note: P4-10 — Workflow Budget, Scheduler, Backpressure, Fairness & Resource Locks
## Problem
No unified token/cost/time/resource vocabulary, global scheduler, or resource locks for multi-agent workflows.
## Contract
- TaskQueue: priority-based with FIFO for same priority
- ResourceLockManager: exclusive/shared locks, per-task release
- FairnessScheduler: tenant fairness with priority aging
- Scheduler: budget, backpressure, concurrency control
## State Machine
submitted → queued → (scheduled|blocked) → (completed|cancelled)
## Failure Semantics
- Max concurrency: blocked
- Resource locked: blocked, re-queued
- Budget exceeded: blocked
- Backpressure: rejected
## Rejection
- Queue full: backpressure
- Budget exceeded: rejected
- Cross-tenant starvation: prevented by fairness aging
