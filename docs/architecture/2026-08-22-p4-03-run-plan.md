# Agent Note: P4-03 — RunPlan

## Problem
Existing workflow meta phases are observational, not structural. There is no unified plan object connecting model route, context topology, agent graph, policy, world, and verification.

## Contract
RunPlan is a frozen, data-only specification with:
- Objectives and constraints
- ModelRoutes (provider, model, fallback)
- AgentGraph (nodes with role, tools, world assignment)
- Worlds (id, kind, policy digest)
- Budgets (tokens, cost, time, agents)
- ApprovalGates (step, approver, deadline)
- Verification (method, criteria, verifier)
- Recovery (maxRetries, checkpoint)
- Digest (SHA-256 of canonicalized plan)

## State Machine
compiled → frozen (P4-04) → executing → completed/failed

## Failure Semantics
- Unsatisfiable constraints return minimal conflict set, no execution
- Missing model/world/budget: compile throws with specific error
- Same normalized inputs produce deterministic plan digest

## Compatibility
- Versioned verificationContractRef extension point for P7-01
- Plan is serializable for persistence and SDK transport
- Old workflow meta remains as observational layer

## Rejection
- Plan with executable code: rejected
- Plan without satisfiability check: rejected
- Plan with mutable fields not pre-declared: rejected at freeze (P4-04)
