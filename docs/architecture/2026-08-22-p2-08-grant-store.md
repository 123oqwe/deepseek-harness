# Agent Note: P2-08 — Reusable Grant, Scope Rules, Expiry & Revocation
## Problem
Single-use approvals cannot express reusable grants with scope, expiry, and cascading revocation.
## Contract
- Grant: id, principal, resource, scope, constraints, issuedAt, expiresAt, parentGrantId, digest
- GrantStore: issue, revoke, match, revokeDescendants
- Scope hierarchy: admin > execute > write > read
## State Machine
issued → active → (expired|revoked|consumed)
## Failure Semantics
- Expired: not matched
- Revoked: not matched, descendants also revoked
- Scope insufficient: not matched
- Amount/destination constraint violated: not matched
## Rejection
- Cross-principal grant: rejected
- Scope escalation: rejected
- Destination mismatch: rejected
