# 控制协议

[English](control-protocol.md) | 中文

SDK 控制协议是 SDK 客户端与 harness 运行时之间的 JSON-RPC 面。本页拥有协商规则；消息形状本身与其类型一起放在 `@deepseek-ai/dsh-sdk-protocol`。

## 两次协商，回答不同的问题

协议协商两次，而把两者混为一谈正是本页要防的错误。

**逐消息的 schema 协商**（`InitializeParams.schemaVersion`，通过 `@deepseek-ai/dsh-schema-registry` 解析）回答的是*这个 build 能否读懂这条消息*。它的作用域是单个消息形状，对整个对端不作任何陈述。

**协议版本协商**（`InitializeParams.protocolVersions`）回答的是*这两个对端究竟能不能一起工作*。客户端需要在**发送任务之前**得到这个答案，而不是在它依赖的某个字段悄悄消失之后。

## 版本区间

每个对端声明一个闭区间。协商返回**双方都支持的最高版本**，或者以一个机器可读的原因拒绝，并带上两侧的区间。

取最高而不是最低是刻意的。版本是一个兼容代际，取最低会把两个对端都压在任一方曾经支持过的最旧形状上——**而一个能力就是这样在没有人决定停用它的情况下停止被使用的**。

规则是对称的：交换客户端与服务端不会改变协商出的版本。不对称的规则会让两个对端对同一组输入得出不同答案，而各自都局部自洽。

`min` 大于 `max` 的区间不描述任何版本。它被拒绝而不是被规范化，因为修复它等于替对端发明一个它从未做出的声明。

## mandatory 与 optional 能力

对端声明能力，每一条标记 mandatory 或 optional。`mandatory` 是**该次声明**的属性，不是能力本身的属性：同一个能力可以被一方要求、被另一方仅仅提供。

无法识别的 **mandatory** 能力拒绝连接。无法识别的 **optional** 能力被忽略并记录——这个不对称正是划分的全部意义，也正是它让较新的对端能提供额外东西而不破坏较旧的对端。

两种拒绝原因被刻意区分开，因为对端可以据此采取不同行动：

| 原因 | 含义 |
|---|---|
| `unknown-mandatory-capability` | 这个 build 从未听说过它——版本偏移 |
| `unsupported-mandatory-capability` | 这个 build 认识它但没有实现——真实缺口 |

协商在第一个 mandatory 失败处 fail fast。任何单独一条都是致命的，所以列出一张清单会暗示它们可以被独立修复。

## Schema 指纹

一个 build 的指纹覆盖它的 **wire 可见形状**：方法名与事件名，各自的 schema id 与版本，以及可寻址的资源类型。除此之外没有别的。

两个要求在这里彼此拉扯，边界就画在它们相遇的地方。指纹对给定 build 必须稳定，所以声明顺序——任何对端都观察不到的东西——不会移动它；一个因重构而报告漂移的指纹就是在报告假漂移，而一个谎报的指纹会不再被查看。它同时必须在协议行为改变时移动，所以版本号提升、新增方法、移除资源类型，以及同一个名字在方法与事件两类之间移动，都会改变它。

字段在哈希前带长度前缀。没有它，一个名为 `a:b` 的方法和 `a`、`b` 这一对方法可能产生相同的摘要。

## 缺席不是同意

每一个协商字段在 wire 上都是可选的，而它的缺席意味着*这个对端早于协商机制*——**绝不意味着*这个对端同意了空集***。

这个区分是承重的。一个把缺失的 `negotiation` 读成空协议的客户端会拒绝每一个较旧的服务端；一个把它读成协商成功的客户端会带着双方都未确认的能力继续运行。两者都是协议要防的静默字段丢失，方向相反。

出于同样的理由，客户端**校验**这些字段而不是信任它们：在 wire 边界上，静态类型只陈述对端**声称**了什么。畸形的区间被丢弃，走与缺席相同的路径；部分成形的 negotiation 被**整体**丢弃——半读的协议比没读更糟，因为调用方会把到货的那几个字段当作权威。

## Provenance

协商的结果——达成的版本、达成的能力、被忽略的能力，以及任何适配器降级——被记录在 Run 上。于是*这两个对端究竟同意了什么*可以仅凭 Run 记录回答，而不需要重放一次已经不存在的握手。

兼容性适配器可以为缺少某个能力的对端搭桥，但它执行的每一次降级都必须连同原因与负责的适配器一起被记录。一个静默降级的适配器无法产出这样的记录，所以一个 Run 的 provenance 要么点名了降级，要么就没有发生过降级。
